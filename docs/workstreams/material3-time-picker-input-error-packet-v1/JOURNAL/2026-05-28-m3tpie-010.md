# M3TPIE-010 Journal

Date: 2026-05-28

Reviewed Compose Material3 TimePicker input behavior and Fret's current implementation.

Conclusion: Fret was clamping invalid editable input into committed time. Compose keeps editable
hour/minute input validity separate from committed state, then renders error text and error chrome.
The Fret fix belongs in `ecosystem/fret-ui-material3`.
