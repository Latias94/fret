# M3TP A11Y 010 - Source Read

Compose `TimePicker.kt` and `TimePickerTest.kt` show three semantics outcomes that Fret was not
fully exposing: display selectors are radio-like selectable controls, dial values have hour/minute
spoken descriptions, and the period toggle has a group content description.

The existing Fret runtime already has the needed mechanisms, so this is recipe work.
