# SMS-010 Select Pointer-Open ArrowDown

Date: 2026-05-17
Status: Done

## Decision

Pointer-open should initialize Select `active_descendant` to the selected item, or to the first valid item when no value is selected. In Fret, pointer-open continues to keep tree focus on the listbox container, but `active_descendant` mirrors Radix's focused item so ArrowDown advances from that row.

## Source Evidence

- `F:/SourceCodes/Rust/fret/repo-ref/ui/apps/v4/registry/new-york-v4/ui/select.tsx`: shadcn v4 Select is a wrapper around `@radix-ui/react-select`.
- `F:/SourceCodes/Rust/fret/repo-ref/primitives/packages/react/select/src/select.tsx`: mouse `onPointerDown` opens through `handleOpen(event)` and prevents the trigger from taking focus.
- `F:/SourceCodes/Rust/fret/repo-ref/primitives/packages/react/select/src/select.tsx`: `focusSelectedItem()` calls `focusFirst([selectedItem, content])` after the content is positioned.
- `F:/SourceCodes/Rust/fret/repo-ref/primitives/packages/react/select/src/select.tsx`: `itemRefCallback` records the selected item, or the first valid item when there is no selected value.
- `F:/SourceCodes/Rust/fret/repo-ref/primitives/packages/react/select/src/select.tsx`: ArrowDown navigation slices candidates after the currently focused item.
- `F:/SourceCodes/Rust/fret/repo-ref/base-ui/packages/react/src/select/root/SelectRoot.tsx`: `useListNavigation` is wired with `activeIndex` and `selectedIndex`, making selected/highlighted state the navigation anchor.
- `F:/SourceCodes/Rust/fret/repo-ref/base-ui/packages/react/src/select/root/SelectRoot.test.tsx`: pointer-open with no selected value highlights the first item when item-trigger alignment is active.
