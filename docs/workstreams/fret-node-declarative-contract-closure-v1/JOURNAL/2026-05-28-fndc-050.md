# FNDC-050 Declarative Interaction Hook Contract - 2026-05-28

## Summary

- Added `NodeGraphDeclarativeInteractionHook` and
  `NodeGraphDeclarativeInteractionContext` as the declarative replacement seam for retained canvas
  middleware.
- Wired `NodeGraphSurfaceProps::interaction_hook` into key-down capture as the first supported hook
  point.
- Kept the hook context store-first: graph edits can be committed through binding dispatch, while
  hooks do not receive `&mut Graph` or raw model-store access.
- Updated ADR 0135 and public node graph guides to teach the hook contract instead of reviving
  `NodeGraphCanvasMiddleware`.

## Validation

- PASS `cargo nextest run -p fret-node declarative_interaction_hook public_node_graph_guides` (3 tests)
- PASS `cargo fmt --check`
- PASS `git diff --check`

## Notes

- Pointer, command, and observer hooks remain follow-ons. They should extend the same
  `NodeGraphDeclarativeInteractionHook` contract rather than creating another middleware family.
