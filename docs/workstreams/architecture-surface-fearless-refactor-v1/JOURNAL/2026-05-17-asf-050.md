# ASF-050 — Boolean Control Taxonomy Slice

Date: 2026-05-17
Status: Complete

## Scope

Chose the boolean-control family (`checkbox` + `switch`) as the first representative primitive
taxonomy slice.

## Shipped State

- `fret-ui-headless::boolean_control` owns pure optional-bool transitions:
  `checkbox_checked_state_from_optional_bool`, `checkbox_toggle_optional_bool`,
  `switch_checked_from_optional_bool`, and `switch_toggle_optional_bool`.
- `fret-ui-kit::primitives::{checkbox,switch}` no longer own those pure helpers. They keep the
  runtime/a11y/model facades (`checkbox_a11y`, `checkbox_use_checked_model`, `switch_a11y`,
  `switch_use_checked_model`).
- shadcn, Material3, editor, gallery, and `fret` LocalState bridge call sites import the headless
  owner directly for pure state.
- ADR 0154 alignment now records that `fret-ui-primitives` remains deleted for v1; this slice uses
  direct headless ownership plus kit runtime facades instead of introducing a micro-crate.
