# ASF-060 — Shared Menu/Select Entry Focus Owner

Date: 2026-05-17
Status: Complete

## Scope

Extracted one concrete shared menu/select interaction behavior without mechanically splitting recipe
files: input-modality-gated entry-focus target selection.

## Shipped State

- `ecosystem/fret-ui-headless/src/entry_focus.rs` owns the pure target-selection policy.
- `fret-ui-kit` menu and select primitives adapt runtime input modality into the headless owner.
- `fret-ui-shadcn::select` now uses the shared select adapter instead of resolving targets through
  a select-local method.
- ADR 0094 alignment points at the headless owner and the kit runtime adapters.
