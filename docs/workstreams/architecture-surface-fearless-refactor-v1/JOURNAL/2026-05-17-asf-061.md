# ASF-061 — Menu/Select Follow-on Split

Date: 2026-05-17
Status: Complete

## Decision

ASF-060 is sufficient for this architecture-surface lane: it proved one shared menu/select behavior
owner and moved the pure policy into `fret-ui-headless`.

Remaining shadcn menu/select policy cleanup is now owned by
`docs/workstreams/shadcn-menu-select-policy-followon-v1/`.

## Rationale

The completed `docs/workstreams/menu-surfaces-alignment-v1/` lane is historical OS/in-window
menubar scope. Reopening it for shadcn recipe/select behavior would blur ownership.

The observed `select_keyboard_navigation` failure is a concrete enough baseline for a narrow
follow-on: pointer-open + ArrowDown + Enter currently selects `"apple"` while the test expects
`"banana"`.
