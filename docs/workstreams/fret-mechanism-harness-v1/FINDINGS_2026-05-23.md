## F272: State-sensitive CachedSubtree cache-key authoring guard is now explicit

- F268 and F271 both left the same narrow follow-up recommendation: state-sensitive cached subtree
  content needs an explicit cache-key dependency so retained/replayed output cannot keep stale
  action-state or relation metadata after the callsite stays stable.

  Combobox disabled-action-state runtime gate already proved the real UI Gallery path. This slice
  targets the authoring/API guard, not another runtime script.

- No new mechanism or recipe defect was reproduced.

  dependency as `u64::from(review_disabled_now)`, which is easy to miss during future fixture or
  recipe review.

  boolean render dependencies beside existing text-style and clip helpers.
- Updated the moving cached Combobox fixture to use `.cache_key_bool(review_disabled_now)`.
- Added a gallery authoring-surface regression that rejects the old ad-hoc
  `u64::from(review_disabled_now)` pattern and keeps the Resizable docs note aligned.
- Updated `docs/component-author-guide.md` to call out typed cache-key helpers for
  state-sensitive cached content.
