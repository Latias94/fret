# Findings 2026-05-14

## F61: Hidden semantics were still selectable by default harness oracles

Layer: `crates/fret-mechanism-harness` observation/oracle semantics filtering +
`crates/fret-ui` declarative semantics fixture coverage

Status: fixed and covered

What was found:

- The semantics metadata fixture had already grown beyond the coverage map: value/editing metadata,
  collection metadata, action surfaces, live-region metadata, numeric metadata, and scroll metadata
  were present and passing.
- The remaining real semantics gap was hidden-subtree policy from ADR 0293. `SemanticsSnapshot`
  intentionally keeps hidden nodes for deterministic diagnostics, but default harness selectors
  should model the filtered accessibility tree.
- `ObservedTree::select_best` filtered invisible roots and input barriers, but did not filter
  `SemanticsFlags.hidden` or descendants of hidden nodes. This could let mechanism fixtures
  incorrectly treat `aria-hidden` / hidden diagnostic nodes as user-facing accessibility matches.
- `semantics_flag_is` also used the default filtered path, so a correct hidden-subtree filter would
  have made it impossible to assert the hidden flag on retained diagnostic nodes.

What was fixed:

- `ObservedTree::node_is_selectable` now excludes nodes whose own semantics flag is hidden or whose
  ancestor is hidden.
- `semantics_flag_is` now uses the unfiltered selector path so diagnostics can still assert hidden
  flags and inspect retained nodes inside hidden subtrees.
- Added a focused harness regression:
  `default_selectors_exclude_semantics_hidden_subtrees_but_flags_remain_queryable`.
- Extended `semantics_relations_v1.json` with
  `hidden-subtree-policy-excludes-default-selectors-but-keeps-diagnostics`, backed by a real
  declarative `SemanticsProps` scenario.

  semantics harness is now strong enough for mechanism proof, but the lane still lacks a runtime
  a11y diagnostics gate comparable to the overlay/focus and TextInput visual gates.

## F62: Scroll/virtual-list runtime gates needed structured instability oracles

Layer: diagnostics protocol + bootstrap script runner + UI Gallery runtime gates

Status: fixed and covered

What was found:

- The Virtual List small-scroll diagnostics script was not a durable runtime gate. It targeted the
  dev-only Virtual List Torture page without recording the `gallery-dev` precondition, and it
  initially used `ui-gallery-virtual-list-root` where the live scroll semantics were actually on
  `ui-gallery-content-viewport-virtual_list_torture`.
- The existing Checkbox RTL scripts could prove "eventually stable" at a short boundary, but could
  not assert "no-input idle stability for N frames." That left the user's RTL scroll jitter report
  hard to convert into a reusable mechanism harness gate.
- The first implementation of idle-stability evidence exposed a second harness defect: the new
  trace was recorded during the assertion, but `note_step_start_and_scope_evidence` dropped it when
  the following capture step started, so passed script results lost the structured sampling proof.
- Current runtime evidence did not reproduce a real RTL scroll mechanism defect on the default
  Checkbox page. The new gate sampled 45 idle frames with no scroll drift.

What was fixed:

- Added `UiPredicateV1::VirtualListWindowShiftSamplesLenLe` so virtual-list debug telemetry can be
  asserted directly from diagnostics scripts.
- Hardened `ui-gallery-virtual-list-small-scroll-no-window-shifts.json` with feature metadata,
  stable navigation, the correct scroll semantics target, diagnostic resets, and `max=0` window-shift
  assertions before and after small wheel deltas.
- Added `assert_semantics_scroll_idle_stable` to diagnostics script v2. It samples a structured
  semantics scroll field for a fixed no-input frame window and fails when single-frame or total
  drift exceeds configured thresholds.
- Added `UiSemanticsScrollIdleStableTraceEntryV1` evidence and retained it across later capture
  steps so passed scripts keep their final sampling proof.
- Promoted `ui-gallery-checkbox-scroll-to-rtl-field.json` into `ui-gallery-rtl-smoke` and
  `ui-gallery-shadcn-conformance`.
