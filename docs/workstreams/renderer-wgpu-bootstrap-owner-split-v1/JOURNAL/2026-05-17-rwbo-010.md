# RWBO-010 — WGPU Bootstrap Owner Split

Date: 2026-05-17

## Decision

Move the WGPU bootstrap implementation out of the backend crate root into a private `context` owner
module without changing public paths, GPU selection policy, fallback policy, environment variables,
diagnostics schema, or renderer facade buckets.

## Changes

- Added `crates/fret-render-wgpu/src/context.rs` for `WgpuContext`, init diagnostics, adapter
  selection snapshots, backend override parsing, environment helpers, adapter validation, and parse
  tests.
- Updated `crates/fret-render-wgpu/src/lib.rs` to declare `mod context;` and re-export the public
  context/snapshot types.
- Left `crates/fret-render/src/lib.rs` and facade snapshot expectations unchanged.
