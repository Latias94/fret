# M3CAS-080 Closeout - Choice Controls And Chips

Date: 2026-05-27

## Summary

Closed the choice-control and chip packet. The packet did not justify a new Material foundation
refactor: shared state-layer/ripple behavior already routes through `foundation::indication`, and
minimum touch target behavior already routes through `foundation::interactive_size`.

## Changes

- Added automation-surface coverage for Checkbox, RadioGroup/Radio, IconButton, IconToggleButton,
  Slider, RangeSlider, SegmentedButtonSet, ChipSet, AssistChip, SuggestionChip, FilterChip, and
  InputChip.
- Recorded stable root/chrome selectors for choice controls and chips.
- Recorded Slider and RangeSlider selector boundaries: root/range thumb semantics are selectors;
  internal track/handle/state-layer paint remains canvas scene evidence.
- Updated the component matrix, task ledger, milestones, evidence log, selector audit, and handoff.

## Layer Decisions

- `material_foundation`: shared indication state-layer/ripple behavior and minimum interactive
  target sizing.
- `material_recipe`: checked/selected semantics, selected indicators, slider state machines,
  segmented button roles, chip trailing actions, and stable selectors.
- `kit_policy`: no immediate extraction; RadioGroup/ChipSet/Segmented roving can move only after
  another design-system consumer proves shared policy value.
- `diagnostics`: Slider internal canvas parts need named draw-region diagnostics before they should
  become part selectors.

## Gates

- `cargo nextest run -p fret-ui-material3 --features diagnostics --test automation_surface`
- Focused `radio_alignment` gates for checkbox, radio, switch, icon button, chips, segmented
  buttons, and slider/segmented headless goldens.

## Follow-Ons

- Add diagnostics support for named canvas draw regions before exposing slider internal paint part
  selectors.
- Revisit `fret-ui-kit` extraction for roving/typeahead only if another design system needs the
  same group policy.
- Split broader chip visual parity only if gallery diagnostics show spacing/elevation drift.
