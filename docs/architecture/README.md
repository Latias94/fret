# Architecture Planner Registry

This directory contains planner-facing architecture lane maps.

Authoritative architecture remains in:

- `docs/architecture.md`
- `docs/golden-architecture.md`
- accepted ADRs under `docs/adr/`

Use `LANES.md` to route active workstreams to long-lived Codex terminals and worktrees. Do not use
this directory as a replacement for ADRs, closeout audits, or workstream evidence.
